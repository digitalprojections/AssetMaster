npm package

For technical users on systems with Node.js 22 or newer. Install the downloaded tarball and configure your local MCP client.

Download npm package
npm install -g ./assetmaster-mcp-server-1.1.19.tgz
assetmaster-mcp --config --workspace /path/to/assets

Connect in a few steps

  1. Extract the Windows archive and run install.ps1 in PowerShell, or install the npm tarball.
  2. Choose a dedicated assets folder using --workspace. Add the executable and arguments printed by --config to your AI application's local MCP settings.
  3. Ask the agent to check assetmaster_status. Open its local pairing URL directly in your browser.
  4. Follow Open AssetMaster to connect, then select Connect workspace. Keep the local pairing page open; it securely relays the connection.
  5. Keep the editor and local pairing page open. Ask the agent to import an image, create a cutout, preview it and export a PNG to a new filename.

Designed for MCP clients that can launch a local stdio process. Client-specific one-click installation and remote-only AI clients are not supported by this download. The companion and browser run on the same computer.

Local editing, explicit sharing

Editing runs in your browser. The agent can access only the configured folder. Requested image previews and returned content are shared with your AI application and may reach its model provider.

Pairing credentials stay in memory. Disconnect from AI integrations at any time.

Recovery and updates

Use --doctor to check the runtime, folder and local port. If a connection drops, inspect the editor before repeating an edit.

Install updates alongside the previous version and update the client path. The uninstaller preserves your assets, exports and browser projects.
